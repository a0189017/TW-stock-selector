# 選股輸出格式規範（Output Schema）

本文件是 TW-stock-selector 所有工具輸出的**正式格式規範**。MCP 工具的結果由 LLM
（Claude Desktop）消化，因此格式遵循 harness engineering 原則：給模型乾淨、可運算的
原始資料，由模型負責呈現。

> **唯一事實來源**：`analysis/common.py` 的 `serialize_tech / serialize_chip /
> serialize_fundamental` 與 `SCHEMA_VERSION`。改動格式時同步更新本文件並 bump 版本。

目前版本：**`格式版本` = "1.0"**

---

## 通用規則

1. **數值用原始值**，不預先格式化成字串。例：`"收盤": 950.0`、`"外資今日淨買_張": 1234`、
   `"月營收YoY_%": 15.0`。模型自行決定顯示格式（千分位、正負號、小數位）。
2. **鍵名用中文**，**單位以底線後綴寫入鍵名**：`_張`、`_口`、`_%`、`_億`、`_元`、`_點`、`_日`。
   無單位歧義者免後綴（`收盤`、`代號`、`KD_K`）。
3. **缺值用 `null`**（JSON null / Python None），不是 `"—"` 或 `0`。
   "0" 代表「有資料且為零」，`null` 代表「無資料」。
4. **分類標籤維持字串**：`均線結構`（多頭排列/短多/空頭排列/整理）、
   `相對大盤強度`（明顯強於大盤/略強於大盤/與大盤同步/略弱於大盤/明顯弱於大盤）、
   `價差解讀`、`外資期貨方向`、`預判建議`。
5. **每個工具輸出 root 帶 `"格式版本"`**。
6. **數值精度**：價/指標 2 位小數；張/口/家數取整數；百分比 2 位小數；MACD 柱原值。
7. **錯誤統一格式**：`{"error": {"訊息": "...", "traceback": "...(可選)"}}`。

## 共用區塊

### 技術指標（`serialize_tech`）
```json
{
  "KD_K": 75.2, "KD_D": 68.5, "RSI": 62.0, "布林%B": 0.45,
  "MACD柱": 0.1234,
  "乖離_MA5_%": 1.5, "乖離_MA20_%": 2.0, "乖離_MA60_%": 3.0,
  "量比": 1.5,
  "均線結構": "多頭排列",
  "相對大盤強度": "略強於大盤", "RS_20日_%": 5.2,
  "MA20": 880.0, "MA60": 850.0
}
```
`full=True` 時額外含 `MA5 / MA10 / MA120 / MA240`（單股深度分析用）。

### 籌碼（`serialize_chip`）
```json
{
  "外資今日淨買_張": 1234, "外資5日淨買_張": 5000, "外資連續買超_日": 3,
  "投信今日淨買_張": 500, "三大法人今日淨買_張": 1500,
  "融資餘額變化_%": 5.0, "融資使用率_%": 40.0,
  "融券餘額變化_%": 2.0, "券資比_%": 10.0
}
```

### 基本面（`serialize_fundamental`）
無資料時整個區塊回 `{}`；個別欄位缺值為 `null`。
```json
{ "最新月營收_億": 2300.0, "月營收YoY_%": 15.0, "月營收MoM_%": 3.0, "營收月份": "2026-05" }
```

## 版本政策

任何 `serialize_*` 的鍵名或數值語意變動 → bump `SCHEMA_VERSION`、更新本文件、更新
`tests/test_common.py` 的契約測試（鍵名集合常數 `TECH_KEYS / CHIP_KEYS / FUNDAMENTAL_KEYS`）。
